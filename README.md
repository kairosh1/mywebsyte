# Romantic Date V2
Мобильное романтическое приглашение на свидание.

Запуск: `npm install` затем `npm start`, открыть `/admin.html`.

Для телефона в той же Wi‑Fi сети используй IP компьютера, например `http://192.168.1.10:3000`.

Для отправки девушке нужен публичный HTTPS-хостинг. После размещения ссылка `/invite/ID` открывается на iPhone и Android без установки приложения.
